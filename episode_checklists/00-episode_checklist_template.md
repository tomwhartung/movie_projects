
# 00-episode_checklist_template.md

Our goal is for each episode to have as many of these features as possible, for consistency.

- However, not all episodes will have all of these features, and I think it would be nice to track how we do with each one of them.

Plus, I am really into checklists these days!

# Episode Feature Checklist Template

- [ ] Prefer long format, landscape movies - but note that youtube wants to also see some shorts, so we will want to do some of those too
  - [ ] 'X' indicates this movie is a long format piece, done in landscape orientation
  - [ ] 'X' indicates this movie is a short format piece, done in portrait orientation
- [ ] Required: *All* movies *should* have some sort of **conflict** going on
  - [ ] **CONFLICT IS KEY** to getting people to watch your movies
  - [ ] *Obvious exceptions:* Relaxing, chill, ASMR-type movies
- [ ] Required: *All* movies *must* have a deliberate, distinct Beginning, Middle, and End
  - [ ] Preferred: especially when there is some *conflict*, end with some sort of resolution, a *victory* or some other *positive* note
    - [ ] *Exceptions:* sometimes we will want to leave the viewer unsettled, ala. Bertolt Brect, Spike Lee, etc.
- [ ] Preferred: When possible, use multiple cameras - especially when indoors - don't be just a "*talking head*"
  - [ ] Don't be afraid to leave older cameras rolling to capture "*B-roll*", then use only bits and pieces of those shots
  - [ ] *Exceptions:* Relaxing, chill, outdoors nature-type movies
- [ ] Preferred: When possible, use some camera movement to keep things as interesting as possible
- [ ] Required: Custom music written and performed by me
  - [ ] **Take notes** to help remember how I do this, so I can make how-to movies for others
  - [ ] Start with a "*scratch*" tune
  - [ ] Jam around with the "*scratch*" tune, changing the tempo, rhythm, order of the notes, etc.
  - [ ] Find a short 1-4 measure riff or "*melodie courte*" to use as a theme, between scenes, and at the end
- [ ] Use high-quality microphones
  - [ ] Experiment and test out the microphones I have to see which ones work best in which circumstances
- [ ] When getting emotional and using profanity, make two versions, ala. Hip-Hop:
  - [ ] 'X' indicates this version is a *clean* video
  - [ ] 'X' indicates the original version has profanity - *clearly label it **EXPLICIT** *
    - [ ] Be sure to indicate in the text for the video that a **CLEAN** version is available, and provide the URL for it
  - [ ] 'X' indicates this version is a *clean* version of a video that has cussing - *clearly label it **CLEAN** *
    - [ ] Be sure to indicate in the text for the video that an **EXPLICIT** version is available, and provide the URL for it
- [ ] A Key Idea is to use "*Chiaroscuro*" - contrasts in content, lighting, pace, editing, sound etc. - instead of just being "*blah*"
  - [ ] Toy with the idea of actually *lying* about things, only to reveal in a subsequent episode the *truth*
    - [ ] The idea is to help people build up their *BS Detector* by sharing certain *tells* so they can know when someone's being *biased*
- [ ] The General Idea is to take **only the best** takes and cuts, and *don't be afraid* to leave a lot of it in the "*cutting room floor*"
